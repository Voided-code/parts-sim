Which one?

Native app (C++ and Qt): the fastest option. Its CPU solvers run about ten times faster than the Electron app’s, and its airflow uses the GPU through Metal, Direct3D 12 or Vulkan.

Desktop app (Electron): the same app as the web page in a desktop shell. It has native menus, Open With from Finder or Explorer, and opens files from the command line. Its GPU path is whatever Chromium picks.

Both run the same studies. If unsure, take the native app where one is listed for your system.

First launch

The downloads are not code-signed yet. On macOS, right-click the app, choose Open, then confirm. On Windows, choose More info, then Run anyway.

Checking a download

Every card shows the file’s SHA-256 and the command that prints it on your system. The two must match. GitHub also shows a digest next to each file on the release page.

The page asks api.github.com for the latest release when it opens, so the buttons follow what exists. Nothing else leaves your browser.
